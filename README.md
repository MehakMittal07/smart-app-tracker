# Smart App Tracker

A full-stack web app that automatically scans your Gmail for internship, 
certification, and hackathon opportunities. Tracks deadlines and sends reminders.

## Tech Stack
- Backend: Spring Boot 3.2, Spring Security 6, Google OAuth2, Gmail API, MySQL
- Frontend: React + Vite, deployed on Vercel
- Database: MySQL on Railway
- Deployment: Railway (backend) + Vercel (frontend)

## Live Demo
https://smart-app-tracker.vercel.app

## Features
- Google OAuth2 login
- Automatic Gmail scanning
- Kanban task board
- Deadline reminders via email
- Auto-expiry of missed opportunities
